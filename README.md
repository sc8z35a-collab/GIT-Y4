# NARROW-50 — 深い森の 5m × 10m 狭小平屋 1LDK 一人称探索エンジン

5,000 mm × 10,000 mm（50.00 m² / 15.13 坪）の狭小平屋 1LDK を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 TBDR / 1.5K 120Hz AMOLED）** を大前提として設計・最適化したリアルタイム一人称 3D 内装探索 & JIS 1/50 実施設計図面アプリケーションです。

## 体験コンセプト
- **内観スポーン型・純一人称視点**：俯瞰視点・カットアウェイ・時刻切替などの周辺設定を排し、起動直後から暗い室内（LDK）に立つ主人公として全室・玄関ポーチ・深い森の縁を歩き回れます。
- **暗く親密なナイトライティング × 深い森の奥**：ダイニングのペンダント灯・小上がり畳の和紙行灯・ウッドスラット壁の間接 LED・ベッドサイド灯などの限られた温光と、窓外に広がる 260 本超の鬱蒼とした杉林・月光・地這い霧・蛍の対比。
- **POCO F7 最適化デュアルサム操作 + デスクトップ FPS 操作**：左画面フローティングアナログスティック（外周 85% で速歩）＋右画面タッチ視点＋ハプティクス振動／デスクトップ `WASD`・`Shift`・`C`・マウス視点・`E` 開閉・`F` 懐中電灯・`M` 1/50 実施設計間取り図・`P` F7 テレメトリ。

## POCO F7（Adreno 825 TBDR / 120Hz）向け革新技術・最適化アーキテクチャ

1. **マテリアル・バケット静的ジオメトリ自動バッチャー（`src/mobileBatcher.js`）**
   - マルチマテリアル `BoxGeometry` を面グループ単位で分解・ワールド変換ベイク・マテリアル単位で統合し、静的建築/家具のドローコールを **約 70〜80% 削減**。
2. **量子化マテリアル重複排除 & ランタイム Sobel 法線マップ合成（`src/textures.js`）**
   - 提供素材 15 枚（74 テクスチャ）に対し、Adreno 825 最適異方性フィルタリング（`anisotropy = 4`）と 256×256 オフスクリーン Sobel 勾配法線マップをランタイム合成し、暗所の懐中電灯・行灯で木目・飴色タイル・畳・焼杉板の立体陰影を表現。
3. **120Hz / 60Hz 自動適応型 Dynamic Resolution Scaler (DRS) & オンデマンド影キャッシュ（`src/adaptiveEngine.js`）**
   - 移動平均フレーム時間から解像度スケールを `[0.85x .. 2.0x]` でヒステリシス制御。
   - `shadowMap.autoUpdate = false` による静的シャドウキャッシュで、扉開閉時または懐中電灯移動時のみ影を再描画しモバイル GPU 負荷を大幅削減。
   - **空間ポータル室別ライト予算カリング**：閉じた扉の奥にある光源を自動減衰・非表示化し、フラグメントあたりのアクティブ光源数を常時最適化。
4. **単一パス TBDR シネマティック Post-FX パイプライン（`src/postfx.js`）**
   - マルチパス Bloom のメモリ帯域浪費を回避し、Half-Float + 2x タイル MSAA レンダーターゲットから **1 パス・フルスクリーントライアングル** で 9 タップ解析ブルーム・ACES Filmic ナイトスプリットトーン・暗順応自動露出・AMOLED バンディング防止ディザフィルムグレインを同時実行。
5. **TBDR 向け解析ボリュメトリック月光・地這い森霧・GPU 頂点風揺れ（`src/volumetricAtmosphere.js`）**
   - レイマーチング不使用の Fresnel + 3D 塵ノイズ GLSL 月光シャフト、家屋フットプリントを自動マスクした FBM 地這い森霧、`onBeforeCompile` GPU 頂点シェーダによる 260 本の杉林の風揺れ（CPU 更新ゼロ）。
6. **ゼロ GC ホットループ & Web Audio API プロシージャル空間音響（`src/scene3d.js`, `src/audioEngine.js`）**
   - 毎フレームの `Vector3`/`Euler` アロケーションを排除し GC スパイクをゼロ化。
   - 屋内/屋外および玄関ドア開閉・南窓距離に応じたローパス遮蔽付き森の風音＋床材別（オーク/テラゾー/本畳/森の土）の足音合成。
