# NARROW-50 ＋ 隣棟 ANNEX-40 ＋ RC倉庫棟 ＋ 巨大キャンピングカー CAMPER-75 — 深い森の4棟14図面 一人称3D探索 & 実施設計図 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **母屋（5m×10m 地下1階セメント倉庫＋地上4階＋屋根裏）**、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5m×8m 3階建6室＋1m×1.6mバルコニー×3＋5室屋根裏）**、母屋東1.6mの **コンクリート倉庫棟（2m×2m 低天井2階建・計4室）**、そして本拠点東隣に駐車され **厳格な当たり判定付きで実際に森の中を運転移動できる巨大オーバーランド・キャンピングカー「CAMPER-75」（2.7m×7.5m×高さ3.4m・1F全14室＋極狭W460廊下＋高天井CH3.02m＋2Fロフト2室）** の **全4棟・14図面** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 1. 母屋「NARROW-50 TOWER」（5m×10m・全6層：B1F / 1F / 2F / 3F / 4F / 屋根裏）

- **5層積層直階段コア（`ST0`〜`ST4`）**: 有効幅 `1,000mm`, 13段 × 5層を一直線に積層配置し、一人称徒歩のまま **B1F ↔ 1F ↔ 2F ↔ 3F ↔ 4F（バルコニー含む）↔ 屋根裏部屋** まで途切れなく昇降可能。
- **B1F 地下1階（`B1FL-2,400 / 低天井 CH2,020`）**: 灰色セメント打放し擁壁＋薄明作業灯。内法 **3m×7m の単一セメント主空間（`B01`）** に **倉庫3室（`B02`・`B03`・`B04`）** を併設し、各室に **4段スチール棚を5基ずつ（計15基）** 配置。
- **1F〜3F（`CH2,450〜2,500`）**: 玄関土間（`D1-1`から中庭・隣棟・東コンクリート倉庫棟・巨大キャンピングカー駐車帯へ徒歩直結）、全幅LDK＋小上がり畳ヌック、2F森の書斎・1317浴槽・11帖主寝室、3F琉球畳茶室・黒大理石バー＆アトリエ。
- **4F（`4FL+8,150 / CH2,150`）**: プロデザイナー監修・全室引戸の **5室構成（居室効率 77.4%）** ＋歩行可能な **1m×2m 樹冠バルコニー**。
- **母屋屋根裏（`RFL+10,500 / 6寸勾配`）**: 現し垂木＆棟木、アイアン安全柵吹抜、北保管庫、南・秘密の小屋裏読書室。

## 2. 隣棟「森の離れ」ANNEX-40（5m×8m・3階建＋5室屋根裏・全4層）

母屋西側に **幅 2.60 m の石灯籠苔中庭** を挟んで隣接配置（ワールド座標 `X=-7.60..-2.60m, Z=1.00..9.00m`）。連続積層階段 **`STA1` → `STA2` → `STA3`** により 1F から 3F の3つのバルコニー、さらに5室の屋根裏部屋まで完全徒歩往来できます。

- **隣棟 1F（`A1FL±0 / 40.00 m²`）**: 土間玄関（`DA-1`）、北アトリエ土間、シャワー洗面WC、階段ギャラリー、森のカフェLDK（赤煉瓦壁・デニムソファ・カフェキッチン・点灯可能な離れフロアランプ）。
- **隣棟 2F（`A2FL+2,750 / 40.00 m²`）**: 北書庫ホール、階段ギャラリー前室（`STA2`昇降口）、和モダン琉球畳客室（`DA-3`障子引戸）、森見主寝室（`DA-4`）。
- **隣棟 3F（`A3FL+5,500 / CH2,400`）— 全室引戸 6部屋 ＋ 1.0m×1.6m バルコニー × 3基**:
  - **6部屋**: ① `A301` 北西ミニ書斎室、② `A302` 北東フォレストゲスト室、③ `A303` 東中樹冠書庫ルーム、④ `A304` 東・茶小間＆ドレス室（琉球畳）、⑤ `A305` 南西・森のアトリエ室、⑥ `A306` 南東・スカイサロン室（＋集中ギャラリー `A300`）。
  - **1m×1.6m 歩行可能バルコニー × 3**: 北バルコニー `ABAL-1`（`DA3-B1`）、西バルコニー `ABAL-2`（`DA3-B2`）、南バルコニー `ABAL-3`（`DA3-B3`）。
- **隣棟 屋根裏部屋（`ARFL+8,150 / 6寸勾配`）— 全5部屋**: ① `AR01` 北西星見ノック、② `AR02` 北東アーカイブ室、③ `AR03` 東中ホビールーム、④ `AR04` 南西古書読書室、⑤ `AR05` 南東秘密の畳室。

## 3. 別棟「コンクリート倉庫棟」STORAGE-4（2m×2m・低天井2階建・計4室）

母屋東側に **幅 1.60 m のコンクリート歩道** を挟んで独立建造（ワールド座標 `X=6.60..8.60m, Z=-1.20..0.80m`）。Pコン打放し＆金鏝押えの **灰色コンクリート固め・低天井 `CH 1,920 mm`** の堅牢な2階建バンカー倉庫（延床 `8.00 m²`）です。

- **倉庫 1F（`S1FL±0 / CH1,920 / 2室`）**: 重鋼製外開き扉 `DS-1` → `S101`（1/4）＋鋼製引戸 `DS-12` → `S102`（2/4）。
- **倉庫 2F（`S2FL+2,120 / CH1,920 / 2室`）**: 外付け工業用スチール階段 `STS1`（11段）→ 2F鋼製グレーチング踊場 → `DS-2` → `S201`（3/4）＋`DS-22` → `S202`（4/4）。

## 4. 移動拠点「巨大キャンピングカー」CAMPER-75（2.7m×7.5m×高さ3.4m・運転可動・全2層）

本拠点のすぐ東隣（初期駐車座標 `X=6.40..9.10m, Z=2.00..9.50m`、母屋から東 `1.40m`・倉庫棟から南 `1.20m`）に設置された、**全幅 `2.70m` × 全長 `7.50m` × 全高 `3.40m`（厳密寸法）** の6輪駆動（6×6）オーバーランド・キャンピングカーです。

- **1F（`C1FL+300` / 中央吹抜高天井 `CH 3,020 mm`・ロフト下 `CH 1,980 mm`）— 全14室＋極狭 `W 460 mm` 廊下**:
  - **極狭中央廊下 `C00`（有効幅 `460 mm`）**: 主人公の当たり判定直径 `400 mm` に対して **左右わずか `30 mm` ずつ** というギリギリ収まる極狭スパイン設計（軸分離ウォールスライディングで引っ掛かりゼロ通行）。中央頭上はオーク化粧垂木＆天窓付きの **`CH 3,020 mm` 高天井吹抜**！
  - **指定10室＋その他4室＝1F全14室**（西翼・東翼に高密度配置、全室引戸＆家具・設備内蔵）:
    1. `C01` **運転室**（回転ハンドルに `[E]` で乗車運転・OLED計器盤・パノラマフロントガラス）
    2. `C02` **座席室**（対面デニムシート・折畳オーク卓）
    3. `C03` **キッチン**（2口IH・ステンレスシンク・吊戸棚）
    4. `C04` **お風呂**（防滑ブルータイル・温水張り深型浴槽）
    5. `C05` **シャワー室**（オーバーヘッドレインシャワー・グレーチング排水）
    6. `C06` **トイレ室**（船舶RVトイレ・小型手洗器）
    7. `C07` **1F寝室**（造作キャビンベッド・東/南2面採光窓）
    8. `C08` **クローゼット室**（ハンガー収納・姿見鏡）
    9. `C09` **保管室**（装備ラック・木箱クレート）
    10. `C10` **シェルター室**（無窓鋼鉄装甲板＋装甲扉 `DC-10`・HEPA空気清浄機・非常食・赤色警戒灯）
    11. `C11` **通信・ナビ制御室**（その他① 衛星レーダー・無線卓）
    12. `C12` **ランドリー乾燥室**（その他② ドラム洗濯乾燥機・作業天板）
    13. `C13` **発電・蓄電池室**（その他③ 20kWh LiFePO4 バッテリーラック）
    14. `C14` **応急・工作整備室**（その他④ 工具ペグボード・作業台・赤十字救急箱）
- **2F ロフト（`C2FL+2,340 / CH 980 mm`）— ロフト2室＋ガラス手摺連絡ブリッジ**:
  - 後部急勾配タラップ階段 **`STC1`（9段）** から昇降。**① `CL01` 前方スカイ寝台ロフト（3.3帖・キングマットレス＆天窓）** と **② `CL02` 後方展望＆収納ロフト（3.3帖・琉球畳＆装備箱）** を、1F吹抜 `CH 3,020 mm` を見下ろす **強化ガラス手摺ブリッジ `CL00`** で連結。
- **厳格な当たり判定付き走行システム**:
  - 運転室ハンドルで `[E]` を押すと運転モードへ移行（`W/S` 前進・後退、`A/D` アッカーマン操舵＋前輪＆ハンドル連動回転、`H`/`F` ツインLEDハイビーム、`E` 停車降車、プロシージャル・ディーゼル音＆衝突衝撃音）。
  - **2D 分離軸定理（SAT）OBB vs AABB** により母屋・隣棟・RC倉庫棟（ポーチ・縁側・外階段含む）への貫通を完全阻止し、さらに **OBB vs 円判定** により森の全老杉幹・巨岩・石灯籠・敷地境界とも厳格に衝突判定（3サブステップ掃引でゼロ貫通停止）。どの座標・回転角に停車しても車内14室＋2Fロフトのローカル座標系当たり判定＆15枚の扉・霧マスクが完全に追従します。

## 5. POCO F7（Adreno 825 TBDR / 120Hz）最適化 & 14図面 JIS CAD / PWA
