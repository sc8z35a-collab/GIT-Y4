# NARROW-50 (地下3層＋地上6階＋直通リアルELV・全10層) ＋ 隣棟 ＋ RC倉庫棟 ＋ 巨大RV ＋ 日常軽バン KEI-340 — 深い森の5拠点19図面 一人称3D探索 & 実施設計図 (PWA)

深い老杉の森（樹高22〜34m）の奥に佇む **母屋（地下3層：B3F W520通路→地上直通リアルエレベーター・3.2m×12.5m木造シェルター・奥扉2m×6m食料備蓄倉庫／B2F 10m×10m高天井木床×コンクリート＆全面鏡スタジオ＋4m×6m接続2室／B1Fセメント倉庫＋地上6階SRCハイブリッド耐震塔屋＋6寸勾配屋根裏＝全10層・最高高さ18.93m＋避雷針20.42m）**、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5m×8m 3階建6室＋1m×1.6mバルコニー×3＋5室屋根裏）**、母屋東1.6mの **コンクリート倉庫棟（2m×2m 低天井2階建・計4室）**、本拠点東隣の **巨大キャンピングカー「CAMPER-75」（2.7m×7.5m×高さ3.4m・拡幅W560mm廊下・1F全14室＋2Fロフト2室）**、そして母屋北玄関前の **主人公が日常使いしている軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・運転席1席のみ＋進入可能フルフラット荷室）** の **全5拠点・19図面** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築＆機械探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 2. 隣棟「森の離れ」ANNEX-40（5m×8m・3階建＋5室屋根裏・全4層）

## 4. 移動拠点「巨大キャンピングカー」CAMPER-75（2.7m×7.5m×高さ3.4m・拡幅W560廊下・運転可動）

## 5. 日常使い軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・1席＋進入可能荷室・運転可動）
