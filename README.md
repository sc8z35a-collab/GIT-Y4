# NARROW-50 地下3層＋直通リアルELV ＋ 隣棟 ＋ RC倉庫棟 ＋ 巨大RV ＋ 日常軽バン KEI-340 — 深い森の5拠点17図面 一人称3D探索 & 実施設計図 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **母屋（地下3層：B3F 主人公幅1.3倍通路→地上直通リアルエレベーター・3.2m×12.5m木造シェルター・奥扉2m×6m食料備蓄倉庫／B2F 10m×10m高天井木床×コンクリート＆全面鏡スタジオ＋4m×6m接続2室／B1Fセメント倉庫＋地上4階＋屋根裏＝全8層）**、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5m×8m 3階建6室＋1m×1.6mバルコニー×3＋5室屋根裏）**、母屋東1.6mの **コンクリート倉庫棟（2m×2m 低天井2階建・計4室）**、本拠点東隣の **巨大キャンピングカー「CAMPER-75」（2.7m×7.5m×高さ3.4m・拡幅W560mm廊下・1F全14室＋2Fロフト2室）**、そして母屋北玄関前の **主人公が日常使いしている軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・運転席1席のみ＋進入可能フルフラット荷室）** の **全5拠点・17図面** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築＆機械探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 1. 母屋「NARROW-50 TOWER」（全8層：B3F / B2F / B1F / 1F / 2F / 3F / 4F / 屋根裏）＋ 地上直通リアルエレベーター `ELV-1`

- **超精密 MRL ギヤレス・トラクション式リアルエレベーター `ELV-1`（地下3階 `-10.20m` ⇄ 地上1階 `±0.00m` 一気直通）**:
  - **実働メカニカル機構**: 深さ `1.2m` コンクリートピット（`-11.40m`）に油圧ばね緩衝器×3基＆点検ハシゴ、昇降路全長にT形鋼ガイドレール＆自発光階数ステンシル（`1F / B1 / B2 / B3`）、最上部（1F天井裏・2F床無干渉）に回転する **溝付メイン綱車・そらせ車・調速機・赤色電磁ブレーキ**、4本並行の **実寸伸縮スチールワイヤーロープ**、かごと **逆位相に昇降する鋳鉄製釣合重り（かご背面パノラマガラスからリアルタイム視認可能！）** を完全実装。
  - **連動両開き扉＆S字インバータ制御＆専用音響**: 4フロア全乗場扉とかご扉が完全機械連動してスライドし、ドア閉鎖安全インターロック（未到着の空シャフトへ落下不可・走行中は安全閉鎖）、最高速度 `2.25 m/s` のS字加減速（B3F→1F `10.2m` を約5.6秒で一気に地上到達）、リアルタイム書き換えデジタル階数LED表示、3D大型発光操作盤（COP）＋大型ボタンHUD（`#elevator-hud`）＋キーボード `[1〜4]` 直通選択、インバータ巻上モーター音・電動扉音・日本語2音到着チャイム（「ピンポーン♪」）を搭載。
- **B3F 地下3階（`B3FL-10,200 / CH 2,800`）**:
  - **主人公幅1.3倍の地下通路 `B300`（有効幅 `W 520 mm` ＝ 主人公 `Ø400mm × 1.30` 厳密設計）**: 足元アンバーLED誘導灯付きL字通路を通り抜けると、正面に地上1Fへ一気に昇れる `ELV-1` 乗場が出現。
  - **木の温かみのあるシェルター室（内法 `3.20m × 12.50m = 40.00 m²`）**: 無垢ヒノキ＆オーク床・天然杉羽目板・現し天井梁・暖色ペンダント・暖炉風ヒーター・HEPA陽圧空気清浄機・木製ダイニング＆デニムソファを配した居間（`B301`）に加え、内部に **独立シャワー室（`B302`・レインシャワー＆ヒノキベンチ）**、**独立トイレ室（`B303`・手洗器＆丸鏡）**、**木造寝室（`B304`・クイーン木造ベッド＆書斎机＆B2F階段扉 `DB3-ST`）** を内蔵。
  - **奥の気密扉 `DB3-FD` の先 — 食料備蓄倉庫 `B305`（内法 `2.00m × 6.00m = 12.00 m²`）**: 両側壁に大容量4段木製＆スチール備蓄棚を並べ、20L飲料水ポリタンク群・非常食木箱・米袋・缶詰ケース・奥に大型ステンレス冷蔵庫＆冷凍ストッカーを格納。
- **B2F 地下2階（`B2FL-6,600 / 広大天井 CH 3,800 mm`）— `10m×10m` スタジオ＋`4m×6m` 接続2室**:
  - B1F西壁の専用コンクリート階段 **`ST_B2`（18段）** を降りて正面のスタジオ扉 **`DB2-0`** を開けると、内法 **`10.0m × 10.0m`（`100 m²`）・天井高 `3.80 m`** の開放スタジオ（`B201`）が一気に広がる。無垢オークダンスフローリング、Pコン打放しコンクリート壁＆天井大梁、北・西2面の **床〜天井級大型スタジオミラー×8スパン＆2段オークバー**、吊りトラック照明・木製音響雲・PAスピーカーを完備。
  - スタジオから直結する **`4.0m × 6.0m`（`24 m²`）の接続室を2部屋** 併設：① **`B202` 音響コントロール＆録音室**（扉 `DB2-1`＋大型防音観察窓 `WB2-OBS`・ミキシングコンソール・音響ラック）、② **`B203` 控室＆機材・トレーニング室**（防音引戸 `DB2-2`・姿見鏡・ソファ・機材ケース棚・ウェイトベンチ）。さらに西側の階段 **`ST_B3`（16段）** で B3F シェルターへ徒歩直結。
- **B1F〜4F・屋根裏（全6層継承＋ELV統合）**: B1F灰色セメント3×7m主空間＋倉庫3室（棚15基）＋ELV前室、1F玄関（`1R03`に `ELV-1` 地上直通乗場を開設、玄関扉 `D1-1` から森＆軽バンへ2歩で出られる！）、2F書斎＆主寝室、3F茶室＆黒大理石バー、4Fプロ監修5室＋1×2mバルコニー、6寸勾配屋根裏部屋。

## 2. 隣棟「森の離れ」ANNEX-40（5m×8m・3階建＋5室屋根裏・全4層）

母屋西側に **幅 2.60 m の石灯籠苔中庭** を挟んで隣接配置。連続積層階段 `STA1`〜`STA3` で 1FカフェLDK、2F畳客室＆寝室、**3F 全6部屋＋1.0m×1.6mバルコニー×3基**、**屋根裏 全5部屋** まで完全徒歩探索可能。

## 3. 別棟「コンクリート倉庫棟」STORAGE-4（2m×2m・低天井2階建・計4室）

母屋東側 1.60m に建つ灰色RCコンクリート固め・低天井 `CH 1,920 mm` の2階建バンカー倉庫（1F 2室＋外鉄骨階段 `STS1`＋2F 2室＝計4室）。

## 4. 移動拠点「巨大キャンピングカー」CAMPER-75（2.7m×7.5m×高さ3.4m・拡幅W560廊下・運転可動）

- **通路拡幅アップデート**: 中央スパイン廊下 `C00` を従来の `460 mm` から **`+100 mm` 拡幅した `W 560 mm`**（主人公 `Ø400mm` に対し左右 `80 mm` ずつのゆとり）へ改良し、1F全14室（運転室・座席室・キッチン・お風呂・シャワー・トイレ・寝室・クローゼット・保管室・装甲シェルター・通信・ランドリー・発電・整備室）＋高天井 `CH 3,020 mm` 吹抜＋2Fロフト2室をストレスなく往来可能。

## 5. 日常使い軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・1席＋進入可能荷室・運転可動）

右ハンドル運転席1席のみ＋助手席レス長尺デッキ＋主人公が実際に進入できるフルフラット荷室（`DK-L` 外スライド扉・`DK-R` 跳ね上げハッチ）を備え、巨大RVとの相互 OBB-vs-OBB SAT 厳格衝突判定付きで森の中を自走可能。

## 6. 操作性向上（大型ボタン化）・POCO F7 最適化・17図面 JIS CAD / PWA

- **大型移動＆操作UI**: モバイル左移動スティックを **`152×152px`（ノブ `64px`・方向ガイド常設）**、右アクションボタンを **`78〜86px`**、中央操作プロンプト・上部ボタン・運転ボタンをすべて大型高視認化し、さらにエレベーター内外で **超大型ボタン操作盤（`#elevator-hud`）** が自動表示。
