# NARROW-50 TOWER — 深い森の地下1階＋4階建て＋屋根裏（5m×10m）一人称3D建築探索 & 6層 1/50 実施設計図面 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **5,000 × 10,000 mm（地下1階セメント倉庫＋地上4階建 200.00 m²＋4F 1m×2m樹冠バルコニー＋6寸勾配切妻屋根裏部屋 有効 28.50 m²）** の狭小建築を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 全6層 建築計画（B1F / 1F / 2F / 3F / 4F / 屋根裏部屋）

- **5層積層直階段コア（`ST0`〜`ST4`）**: `X=150..1,150mm, Z=2,450..5,150mm`（有効幅 `1,000mm`, 13段 × 5層）を一直線に積層配置し、一人称操作のまま **B1F ↔ 1F ↔ 2F ↔ 3F ↔ 4F（バルコニー含む）↔ 屋根裏部屋** まで途切れなく歩いて昇降可能。
- **B1F 地下1階（`B1FL-2,400 / 低天井 CH2,020`）**: 灰色セメント打放し擁壁＋露出RC梁の低天井・薄明り地下室。内法 **3,000 × 7,000 mm（3m×7m）の単一セメント主空間（`B01`）** に **地下倉庫3室（`B02`・`B03`・`B04`）** を併設し、**各倉庫に4段スチール倉庫棚を5基ずつ（計15基）** コの字配置（中央歩行スペース確保）。
- **1F（`1FL±0 / CH2,500`）**: 玄関土間、地下階段口ホール（`ST0`降口）、森の道具室・薪パントリー、1Fトイレ、食品庫・水栓室、全幅LDK（木縦格子TV壁・キャラメル煉瓦キッチン・縁側デッキ）、小上がり畳ヌック（和紙行灯）。
- **2F（`2FL+2,750 / CH2,500`）**: 北階段ホール、森の書斎・ワークスタジオ（赤煉瓦×Pコン打放RC・書斎ランプ）、洗面ランドリー、1317森見ユニットバス、11帖主寝室スイート。
- **3F（`3FL+5,500 / CH2,450`）**: 北展望ホール、琉球畳の茶室・客間（セージ漆喰・バックライト和紙障子）、コバルトモザイク＆黒大理石パウダーWC、樹冠アーカイブ納戸、樹冠展望アトリエ・バーラウンジ。
- **4F（`4FL+8,150 / 少し低めの水平強調天井 CH2,150`）**: プロデザイナー監修による **全室引戸（開閉死角ゼロ）＋最小幅900mm集中ギャラリー動線（居室効率 77.4%）の5室構成** ＋ **歩行可能な 1,000 × 2,000 mm（1m×2m）樹冠バルコニー**：
  1. `4R01` 北西・リスニング＆シネマ室（木縦格子吸音壁・レコード機器・低ソファ）
  2. `4R02` 北東・ミニマルゲスト寝室（ローベッド・埋込収納・トラバーチン壁）
  3. `4R03` 東中・ドレス＆パウダースタジオ（壁面ワードローブ・大型鏡ドレッサー）
  4. `4R04` 南西・樹冠ライブラリー＆書斎（壁面フル書棚・樹冠コーナーデスク）
  5. `4R05` 南東・スカイラウンジ（大開口ガラス引戸で書斎と連続＋`D4-6`からバルコニー直結）
  6. `4R07` **4F 樹冠バルコニー（1m×2m）**（地上9m・ウッドデッキ・黒アイアン＋強化ガラス手摺）
- **屋根裏部屋（`RFL+10,500 / 6寸勾配 軒1,420〜棟2,830`）**: 構造合板勾配天井＋現しウォールナット垂木＆棟木、黒スタッドゴム床＆アイアン階段吹抜安全柵、北・小屋裏保管庫（木箱・麻袋・ロープ・クレヨン画）、南・秘密の小屋裏読書室（古畳・花柄妻壁・吊りランタン）。
