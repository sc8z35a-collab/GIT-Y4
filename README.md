# NARROW-50 TOWER — 深い森の3階建て+屋根裏 5m×10m 一人称3D建築探索 & 4層 1/50 実施設計図面 (PWA)

深い老杉の森（樹高16〜24m）の奥に佇む **5,000 × 10,000 mm（地上3階建 150.00 m² + 6寸勾配切妻屋根裏部屋 有効 28.50 m²）** の狭小住宅を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で徹底最適化した WebGL2 一人称リアルタイム建築探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 建築計画（全4層：1F / 2F / 3F / 屋根裏部屋）

- **構造・規模**: 木造軸組工法 地上3階建 ＋ 6寸勾配切妻小屋裏（建築面積 `50.00 m²` / 延床 `150.00 m²` + 小屋裏有効 `28.50 m²`）
- **積層直階段コア（`ST1`〜`ST3`）**: `X=150..1,150mm, Z=2,450..5,150mm`（有効幅 `1,000mm`, 13段 × 3層）を南から北へ連続配置し、全段で有効天井高 `2,550mm` を確保。一人称操作のまま 1F ↔ 2F ↔ 3F ↔ 屋根裏部屋まで途切れなく歩いて昇降できます。
- **1F（`1FL±0 / CH2,500`）**: 玄関土間（白テラゾー・苔石森アプローチ）、玄関ホール、森の道具室・薪パントリー（古杉板・積薪・有孔ボード）、1Fトイレ、食品庫・土間水栓室、全幅LDK（木縦格子TV壁・キャラメル煉瓦キッチン・ダイニング・縁側デッキ）、小上がり畳ヌック（和紙行灯点灯可）。
- **2F（`2FL+2,750 / CH2,500`）**: 北階段ホール、森の書斎・ワークスタジオ（赤煉瓦・Pコン打放RC・コルク＆有孔ボード・書斎ランプ点灯可）、洗面脱衣ランドリー（エメラルド艶タイル・白大理石洗面）、1317森見ユニットバス（濡れ御影石）、11帖主寝室スイート（ウォールナット床・樹冠パノラマ窓）。
- **3F（`3FL+5,500 / CH2,450`）**: 北展望ホール、琉球畳の茶室・客間（セージ漆喰・バックライト和紙障子・ちゃぶ台）、コバルトモザイク＆黒大理石パウダーWC、樹冠アーカイブ納戸、樹冠展望アトリエ・バーラウンジ（古暗煉瓦・黒大理石バー・真鍮メッシュペンダント）。
- **屋根裏部屋（`RFL+8,150 / 6寸勾配 軒1,420〜棟2,830`）**: 構造合板勾配天井＋現しウォールナット垂木＆棟木、黒スタッドゴム床＆アイアン階段吹抜安全柵、北・小屋裏保管庫（木箱・麻袋・ロープ・クレヨン画）、南・秘密の小屋裏読書室（古畳・花柄妻壁・吊りアイアンランタン点灯可・南北切妻展望窓）。

## POCO F7（Adreno 825 TBDR / 120Hz）向け最適化 & 高度技術

1. **Material-Bucketed Static Geometry Batching**（`src/mobileBatcher.js`）: 静的建築・家具メッシュをマテリアル単位に自動統合し、ドローコールを約 60% 削減。
2. **4層空間ポータル光源カリング + オンデマンド影キャッシュ**（`src/adaptiveEngine.js`）: `shadowMap.autoUpdate = false` による静的影キャッシュと、現在フロアに連動した動的ライト制御（常時 ≤ 4〜6 灯）＋ 120Hz / 60Hz 自動判定 Dynamic Resolution Scaler (DRS)。
3. **Adreno 825 安全単一パス Post-FX パイプライン**（`src/postfx.js`）: `EXT_color_buffer_float` プローブと `GL_FRAMEBUFFER_COMPLETE` 実機検証によりモバイル黒画面を完全防止しつつ、9タップ解析ブルーム・ACES映画調トーンマップ・AMOLEDバンディング抑止ディザを1パス合成。
4. **TBDR解析ボリューメトリック月光 & GPU頂点風揺れ**（`src/volumetricAtmosphere.js`）: 1F〜屋根裏まで貫く解析フレネル＋3Dノイズ月光シャフト、屋外限定のFBM霧、CPU負荷ゼロのインスタンス老杉GPU風揺れシェーダ。
5. **121種オリジナル素材テクスチャ＋ランタイムSobel法線合成**（`src/textures.js`）: ユーザー提供アトラスから切り出した全121種PNG素材に対し、主要建築面の256×256法線マップをロード時に動的生成。
6. **プロシージャルWeb Audio音響**（`src/audioEngine.js`）: 外部音声ゼロで深夜の森の風（屋内/窓際/屋根裏の遮音フィルタ連動）、虫の音、床材別足音、ドア・ランタン開閉音をリアルタイム合成。
7. **完全オフラインPWA & GitHub Pages ルートビルド**（`manifest.webmanifest`, `sw.js`, `scripts/postbuild.mjs`）: `display: "fullscreen"` 対応マニフェスト、バージョン自動同期 Service Worker、`アプリ追加` インストールボタンを実装し、GitHub Pages (`main /`) から直接ゼロエラー起動。

## 操作方法

- **PC**: `WASD` / 矢印キー移動（階段はそのまま昇降）、`Shift` 速歩、`C` しゃがむ、クリックでFPS視点ロック（ドラッグ視点も対応）、`E` ドア開閉・照明点灯、`F` 懐中電灯、`M` 4層1/50実施設計間取り図、`P` POCO F7テレメトリ表示
- **モバイル（POCO F7等）**: 左画面アナログ仮想スティック（外周押し込みで速歩）、右画面タッチ視点、右下クイック操作ボタン（操作 / ライト / しゃがむ）

npm run build    # プロダクションビルド → ルート index.html / assets/ / sw.js 更新
