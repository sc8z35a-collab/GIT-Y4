# NARROW-50 地下4層(極秘研)＋ELV Mk2 ＋ 隣棟 ＋ RC倉庫棟 ＋ 巨大RV ＋ 日常軽バン KEI-340 — 深い森の5拠点18図面 一人称3D探索 & 実施設計図 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **母屋（地下4層：B4F エレベーター専用・B3Fより正確に4.0m下の2.7m×15.5m高天井CH3.55m ギャング極秘研究所／B3F 主人公幅1.3倍通路→超精密5停止リアルエレベーター Mk2・3.2m×12.5m木造シェルター・奥扉2m×6m食料備蓄倉庫／B2F 10m×10m高天井木床×コンクリート＆全面鏡スタジオ＋4m×6m接続2室／B1Fセメント倉庫＋地上4階＋屋根裏＝全9層）**、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5m×8m 3階建6室＋1m×1.6mバルコニー×3＋5室屋根裏）**、母屋東1.6mの **コンクリート倉庫棟（2m×2m 低天井2階建・計4室）**、本拠点東隣の **巨大キャンピングカー「CAMPER-75」（2.7m×7.5m×高さ3.4m・拡幅W560mm廊下・1F全14室＋2Fロフト2室）**、そして母屋北玄関前の **主人公が日常使いしている軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・運転席1席のみ＋進入可能フルフラット荷室）** の **全5拠点・18図面** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築＆機械探索アプリ＆オフライン対応 PWA です。

## 2. 隣棟「森の離れ」ANNEX-40（5m×8m・3階建＋5室屋根裏・全4層）

母屋西側に **幅 2.60 m の石灯籠苔中庭** を挟んで隣接配置。連続積層階段 `STA1`〜`STA3` で 1FカフェLDK、2F畳客室＆寝室、**3F 全6部屋＋1.0m×1.6mバルコニー×3基**、**屋根裏 全5部屋** まで完全徒歩探索可能。

## 3. 別棟「コンクリート倉庫棟」STORAGE-4（2m×2m・低天井2階建・計4室）

## 4. 移動拠点「巨大キャンピングカー」CAMPER-75（2.7m×7.5m×高さ3.4m・拡幅W560廊下・運転可動）

中央スパイン廊下 `C00` を **`W 560 mm`** へ拡幅し、1F全14室＋高天井 `CH 3,020 mm` 吹抜＋2Fロフト2室を快適に探索可能。厳格 OBB 衝突判定付きで自走可能。

## 5. 日常使い軽バン「KEI-340」（全長 3.40m × 全幅 1.48m × 全高 1.80m・1席＋進入可能荷室・運転可動）

右ハンドル運転席1席のみ＋助手席レス長尺デッキ＋主人公が実際に進入できるフルフラット荷室（`DK-L` 外スライド扉・`DK-R` 跳ね上げハッチ）を備え、巨大RVとの相互 OBB-vs-OBB SAT 厳格衝突判定付きで森の中を自走可能。
