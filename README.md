# NARROW-50 ＋ 隣棟 ANNEX-40 (3F+屋根裏) ＋ RC倉庫棟 STORAGE-4 — 深い森の3棟12層 一人称3D建築探索 & 12図面実施設計図 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **母屋（5m×10m 地下1階セメント倉庫＋地上4階＋屋根裏）**、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5m×8m 3階建6室＋1m×1.6mバルコニー×3＋5室屋根裏）**、さらに母屋東1.6mに別棟建造した **コンクリート倉庫棟（2m×2m 低天井2階建・計4室）** の **全3棟・12フロア** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 1. 母屋「NARROW-50 TOWER」（5m×10m・全6層：B1F / 1F / 2F / 3F / 4F / 屋根裏）

- **5層積層直階段コア（`ST0`〜`ST4`）**: 有効幅 `1,000mm`, 13段 × 5層を一直線に積層配置し、一人称徒歩のまま **B1F ↔ 1F ↔ 2F ↔ 3F ↔ 4F（バルコニー含む）↔ 屋根裏部屋** まで途切れなく昇降可能。
- **B1F 地下1階（`B1FL-2,400 / 低天井 CH2,020`）**: 灰色セメント打放し擁壁＋薄明作業灯。内法 **3m×7m の単一セメント主空間（`B01`）** に **倉庫3室（`B02`・`B03`・`B04`）** を併設し、各室に **4段スチール棚を5基ずつ（計15基）** 配置。
- **1F〜3F（`CH2,450〜2,500`）**: 玄関土間（`D1-1`から中庭・隣棟・東コンクリート倉庫棟へ徒歩直結）、全幅LDK＋小上がり畳ヌック、2F森の書斎・1317浴槽・11帖主寝室、3F琉球畳茶室・黒大理石バー＆アトリエ。
- **4F（`4FL+8,150 / CH2,150`）**: プロデザイナー監修・全室引戸の **5室構成（居室効率 77.4%）** ＋歩行可能な **1m×2m 樹冠バルコニー**。
- **母屋屋根裏（`RFL+10,500 / 6寸勾配`）**: 現し垂木＆棟木、アイアン安全柵吹抜、北保管庫、南・秘密の小屋裏読書室。

## 2. 隣棟「森の離れ」ANNEX-40（5m×8m・3階建＋5室屋根裏・全4層）

母屋西側に **幅 2.60 m の石灯籠苔中庭** を挟んで隣接配置（ワールド座標 `X=-7.60..-2.60m, Z=1.00..9.00m`）。連続積層階段 **`STA1` → `STA2` → `STA3`** により 1F から 3F の3つのバルコニー、さらに5室の屋根裏部屋まで完全徒歩往来できます。

- **隣棟 1F（`A1FL±0 / 40.00 m²`）**: 土間玄関（`DA-1`）、北アトリエ土間、シャワー洗面WC、階段ギャラリー、森のカフェLDK（赤煉瓦壁・デニムソファ・カフェキッチン・点灯可能な離れフロアランプ）。
- **隣棟 2F（`A2FL+2,750 / 40.00 m²`）**: 北書庫ホール、階段ギャラリー前室（`STA2`昇降口）、和モダン琉球畳客室（`DA-3`障子引戸）、森見主寝室（`DA-4`）。
- **隣棟 3F（`A3FL+5,500 / CH2,400`）— 全室引戸 6部屋 ＋ 1.0m×1.6m バルコニー × 3基**:
  - **6部屋**: ① `A301` 北西ミニ書斎室、② `A302` 北東フォレストゲスト室、③ `A303` 東中樹冠書庫ルーム、④ `A304` 東・茶小間＆ドレス室（琉球畳）、⑤ `A305` 南西・森のアトリエ室、⑥ `A306` 南東・スカイサロン室（＋集中ギャラリー `A300`）。
  - **1m×1.6m 歩行可能バルコニー × 3**: 北バルコニー `ABAL-1`（`A302`より `DA3-B1` で直結）、西バルコニー `ABAL-2`（`A305`より `DA3-B2` で直結）、南バルコニー `ABAL-3`（`A306`より `DA3-B3` で直結）。いずれも耐候ウッドデッキ＋黒アイアン＆強化ガラス手摺。
- **隣棟 屋根裏部屋（`ARFL+8,150 / 6寸勾配 軒1,400〜棟2,800`）— 全5部屋**:
  - 現しウォールナット棟木＆垂木・勾配カット済みの間仕切壁＋ローハイト引戸（`DAR-1`〜`DAR-5`）により屋根貫通ゼロで **5つの独立屋根裏室** を実装：① `AR01` 北西星見ノック、② `AR02` 北東アーカイブ室、③ `AR03` 東中ホビールーム、④ `AR04` 南西古書読書室、⑤ `AR05` 南東秘密の畳室（和紙ランタン）。

## 3. 別棟「コンクリート倉庫棟」STORAGE-4（2m×2m・低天井2階建・計4室）

母屋東側に **幅 1.60 m のコンクリート歩道** を挟んで独立建造（ワールド座標 `X=6.60..8.60m, Z=-1.20..0.80m`）。Pコン打放し＆金鏝押えの **灰色コンクリート固め・低天井 `CH 1,920 mm`** の堅牢な2階建バンカー倉庫（延床 `8.00 m²`）です。

- **倉庫 1F（`S1FL±0 / CH1,920 / 2室`）**: 重鋼製外開き扉 `DS-1` から入る北コンクリート室 `S101`（1/4）と、間仕切鋼製引戸 `DS-12` で直結する南コンクリート室 `S102`（2/4）。各室に3段スチール棚・木箱・天井防湿バルクヘッド灯を完備。
- **倉庫 2F（`S2FL+2,120 / CH1,920 / 2室`）**: 東外壁沿いの **外付け工業用スチール階段 `STS1`（11段）** を上り、北面 **2F鋼製グレーチング踊場（安全手摺付）** から重鋼製扉 `DS-2` を開けて入る北コンクリート室 `S201`（3/4）＋引戸 `DS-22` 直結の南コンクリート室 `S202`（4/4）。低天井に合わせた自動目線調整（`1.44m`）＆硬質なコンクリート足音も実装。

## 4. POCO F7（Adreno 825 TBDR / 120Hz）最適化 & 12図面 JIS CAD / PWA

- **3棟統合マテリアルバケット静的バッチング**（`src/mobileBatcher.js`）、**3棟×12層空間ポータル光源カリング（GPU同時点灯 常時4〜7灯以下）＋オンデマンド影キャッシュ＋120Hz/60Hz DRS**（`src/adaptiveEngine.js`）、**Adreno 825 FBO自動検証単一パスPost-FX**（`src/postfx.js`）、**3棟対応室内霧マスク＆月光シャフト＆GPU老杉風揺れ**（`src/volumetricAtmosphere.js`）、**121種素材＋Sobel法線マップ**（`src/textures.js`）、**3棟・4バルコニー・外階段連動プロシージャル音響**（`src/audioEngine.js`）、**3棟12図面 JIS平面詳細図（倉庫棟は1/28拡大詳細）＋3棟配置断面略図**（`src/blueprint2d.js`）、**オフラインPWA**（`manifest.webmanifest`, `sw.js`）。
