# NARROW-50 TOWER ＋ 隣棟 ANNEX-40 — 深い森の母屋6層（5m×10m）＋隣棟2階建（5m×8m）一人称3D建築探索 & 2棟8図面 1/50 実施設計図 (PWA)

深い老杉の森（樹高20〜31m）の奥に佇む **母屋（5,000 × 10,000 mm / B1Fセメント倉庫＋地上4階＋屋根裏）** と、西2.6mの石灯籠苔中庭越しに建つ **隣棟「森の離れ」（5,000 × 8,000 mm / 木造2階建・片流れ屋根・延床 80.00 m²）** を、**POCO F7（Snapdragon 8s Gen 4 / Adreno 825 / 1.5K 120Hz AMOLED）** 前提で最適化した WebGL2 一人称リアルタイム建築探索アプリ＆オフライン対応 PWA です。

- **ライブ公開 URL（GitHub Pages / PWA）**: https://sc8z35a-collab.github.io/GIT-Y4/

## 母屋 全6層 建築計画（5m×10m：B1F / 1F / 2F / 3F / 4F / 屋根裏部屋）

- **5層積層直階段コア（`ST0`〜`ST4`）**: `X=150..1,150mm, Z=2,450..5,150mm`（有効幅 `1,000mm`, 13段 × 5層）を一直線に積層配置し、一人称操作のまま **B1F ↔ 1F ↔ 2F ↔ 3F ↔ 4F（バルコニー含む）↔ 屋根裏部屋** まで途切れなく歩いて昇降可能。
- **B1F 地下1階（`B1FL-2,400 / 低天井 CH2,020`）**: 灰色セメント打放し擁壁＋露出RC梁の低天井・薄明り地下室。内法 **3,000 × 7,000 mm（3m×7m）の単一セメント主空間（`B01`）** に **地下倉庫3室（`B02`・`B03`・`B04`）** を併設し、**各倉庫に4段スチール倉庫棚を5基ずつ（計15基）** コの字配置（中央歩行スペース確保）。
- **1F（`1FL±0 / CH2,500`）**: 玄関土間（`D1-1` から石灯籠苔中庭・隣棟へ徒歩直結）、地下階段口ホール（`ST0`降口）、森の道具室・薪パントリー、1Fトイレ、食品庫・水栓室、全幅LDK（木縦格子TV壁・キャラメル煉瓦キッチン・縁側デッキ）、小上がり畳ヌック（和紙行灯）。
- **2F（`2FL+2,750 / CH2,500`）**: 北階段ホール、森の書斎・ワークスタジオ（赤煉瓦×Pコン打放RC・書斎ランプ）、洗面ランドリー、1317森見ユニットバス、11帖主寝室スイート。
- **3F（`3FL+5,500 / CH2,450`）**: 北展望ホール、琉球畳の茶室・客間（セージ漆喰・バックライト和紙障子）、コバルトモザイク＆黒大理石パウダーWC、樹冠アーカイブ納戸、樹冠展望アトリエ・バーラウンジ。
- **4F（`4FL+8,150 / 少し低めの水平強調天井 CH2,150`）**: プロデザイナー監修による **全室引戸（開閉死角ゼロ）＋最小幅900mm集中ギャラリー動線（居室効率 77.4%）の5室構成** ＋ **歩行可能な 1,000 × 2,000 mm（1m×2m）樹冠バルコニー**。
- **屋根裏部屋（`RFL+10,500 / 6寸勾配 軒1,420〜棟2,830`）**: 構造合板勾配天井＋現しウォールナット垂木＆棟木、黒スタッドゴム床＆アイアン階段吹抜安全柵、北・小屋裏保管庫、南・秘密の小屋裏読書室。

## 隣棟「森の離れ」ANNEX-40 建築計画（5m×8m・木造2階建て・延床 80.00 m²）

母屋西側に **幅 2.60 m の石灯籠苔中庭** を挟んで隣接配置（ワールド座標 `X=-7.60..-2.60m, Z=1.00..9.00m`）。母屋1F玄関（`D1-1`）から苔石小径と2基の石灯籠を辿り、隣棟玄関（`DA-1`）から室内・`STA1`直階段・隣棟2Fまで **テレポート一切なしで完全徒歩往来** できます。

- **外観・屋根**: 1F 漆喰白壁＋西面古暗煉瓦、2F 深焼杉板張り、西軒 `+5,450mm` → 東棟 `+6,350mm` のモダンな **片流れスレート屋根**。
- **隣棟 1F（`A1FL±0 / CH2,500 / 40.00 m²`）**:
  - `A101` 離れ・土間玄関（御影石グリッド土間・`DA-1` オーク玄関扉）
  - `A102` 離れ・北アトリエ土間（白テラゾー・Pコン打放RC・オーク作業台・コルク壁）
  - `A103` 離れ・洗面・WC・シャワー（市松石タイル・エメラルド艶壁・`DA-2` 引戸）
  - `A104` 離れ・階段ギャラリー（杉板RC階段壁・`STA1` 13段直階段）
  - `A105` 離れ・森のカフェLDK（全幅4.7m・赤煉瓦壁・デニム2Pソファ・キャラメル煉瓦カフェキッチン・点灯切替可能な離れフロアランプ・南森＆東中庭大窓）
- **隣棟 2F（`A2FL+2,750 / CH2,450 / 40.00 m²`）**:
  - `A201` 離れ2F 北書庫・階段ホール（オーク寄木・木縦格子・造作本棚・読書ベンチ）
  - `A202` 離れ2F 中央廊下・鉄柵吹抜（アイアン＋オーク手摺吹抜）
  - `A203` 離れ2F 和モダン畳客室（琉球半帖畳・セージ漆喰・`DA-3` 障子引戸・東中庭窓から母屋タワーを一望）
  - `A204` 離れ2F 森見主寝室（7.8帖・クイーンベッド・花柄アクセント壁・`DA-4` ウォールナット引戸・南西2面老杉森ビュー）
